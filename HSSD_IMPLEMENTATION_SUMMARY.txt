HSSD-ONLY 实现总结
生成日期：2026-08-15

一、结论
仓库正式采集路径已经从 ReplicaCAD 完全迁移到标准 HSSD。
唯一允许的数据集配置是：
data/scene_datasets/hssd-hab/hssd-hab.scene_dataset_config.json

不允许：
- ReplicaCAD 配置或 apt_* 场景
- hssd-hab-uncluttered
- hssd-hab-articulated
- 缺失 HSSD 时自动 fallback
- 运行时生成临时过滤版 scene_dataset_config
- 手工按场景设置 BEV 高度

七、真实 HSSD 受控物体
注册表只选择 HSSD 原生真实 mesh，类别：
cup, bowl, book, bottle, box
运行时使用完整精确 handle；不存在时立即报错，不做 suffix fallback。

八、全量运行顺序
1. 完成官方 hssd-hab LFS 下载。
2. python scripts/build_hssd_object_registry.py --config configs/collector_hssd.json
3. python scripts/preprocess_hssd.py --config configs/collector_hssd.json
4. 用 configs/collector_hssd_smoke.json 跑三 split 高清 smoke。
5. 检查 registry 统计、预览图、磁盘空间。
6. python scripts/generate_dataset.py --config configs/collector_hssd.json --stage all --validation full

九、已知边界
- 官方 HSSD LFS 下载已经完整结束，168 个场景已全部预处理并进入 registry。
- 43 个上下楼层 XZ 投影明显重叠的场景被保守拒绝；没有把含糊楼层混入正式数据。
- semantic.npz 的范围是生成器受控实体；HSSD 原生背景为 0，不伪造房间级语义。
- 多楼层且上下楼层 XZ 高度投影严重重叠时会保守拒绝，避免 BEV 被其他楼层遮挡。
